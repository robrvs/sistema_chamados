# 🏛️ Sistema de Gestão de Demandas — Suporte TI

Sistema web em estilo CRUD desenvolvido para o gerenciamento de chamados técnicos no setor público.

## 🚀 Tecnologias Utilizadas:
- Python 3.13
- Django 6
- Bootstrap 5 (Local)
- SQLite

## ⚙️ Como rodar o projeto localmente:
1. Instale as dependências: `pip install -r requirements.txt`
2. Rode as migrações do banco: `python manage.py migrate`
3. Crie um operador de TI: `python manage.py createsuperuser`
4. Inicie o servidor: `python manage.py runserver`
