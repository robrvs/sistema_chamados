🏛️ Sobre o Sistema de Gestão de Demandas

Esta aplicação foi desenvolvida como projeto prático para a disciplina de Desenvolvimento Web do 3º Semestre do IFRO (Instituto Federal de Rondônia).

O objetivo principal é informatizar e agilizar o fluxo de abertura de Ordens de Serviço (OS) internas para atendimento a servidores públicos com dificuldades tecnológicas habituais do cotidiano, como problemas de hardware, redes, sistemas e acessos.

Versão 1.0.0 (Compacta) • Desenvolvido em Python e Django com SQLite e Bootstrap 5.
